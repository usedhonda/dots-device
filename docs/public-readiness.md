# 公開版の範囲と今後の確認

公開用のコード・文書・デモはMIT、日本語アトラスはNoto由来のOFLです。キャラクター・Wi-Fi設定・トンネルキー・購読情報は各利用者が用意します。メーカーのタッチドライバは別途取得する方式です。

## 公開ソースで再現できるもの

- 生成デモと設定例を使うESP32-C6ビルド。
- キャラ表示、重力に沿う移動、反対側の吹き出し、ページ・質問・単一タップ回答UI。
- 独自の直接HTTPSトンネルクライアントと署名付き回答イベント。
- [Dot指示テンプレート](dot-instructions.md)と[往復確認](normal-chat-device-flow.md)。

## 利用者ごとの確認が必要なもの

- 自分のアカウントでのトンネル・プラグイン・Dotの接続権限と回答購読。
- 実機の通常会話から質問、物理回答、受領までの往復。
- 通常返信からの要約送信。保存した指示は、全返信の自動強制hookではありません。
- 電池だけでの安定動作。Wi-Fi接続時に電源が落ちるケースは未解決です。
- 別ボードへの移植。現在の実機対象はWaveshare ESP32-C6-Touch-LCD-1.47です。

CIのビルド成功は、クラウドの権限・ライブ往復・電池安定性を証明しません。公開ソースを各自の私用トンネルで試すことと、一般配布する公開プラグインを運用することは異なります。[Secure MCP Tunnel公式資料](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)の条件を確認してください。
