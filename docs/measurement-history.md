# 電源・接続の測定履歴

以下のMac SQLiteへの自動集約は旧Mac中継モードの機能です。直接HTTPSモードでは同じ集約は行わず、USBシリアルの `measurements` で端末の記録を確認します。電池単独の安定化は未解決です。

電池側の電圧、起動からの時間、Wi-Fi状態・RSSI、HTTP結果、再起動理由を記録する。端末の起動IDと連番で重複を防ぎ、MacのSQLiteへ保存する。Mac受信時刻は測定時刻とは別であり、オフライン履歴の正確な壁時計時刻は分からない。

電池電圧は基板のGPIO0のADC値を分圧比3倍に換算した推定値。CPUの3.3V電源そのものを測るものではなく、短い電圧低下を取り逃す場合がある。最低電圧も測定できた値の最小値である。USB接続中は充電・給電条件が変わるため、電池だけの動作と混同しない。

履歴取得は認証付き `GET /admin/device/measurements`（Macローカル限定、直近1000件）。全保存履歴をCSVへ出力する場合はプロジェクト直下で:

```sh
python3 tools/export_measurements.py
```

CSVの既定保存先は `.local/device-measurements.csv`。Wi-Fiが復帰しない場合はUSB接続後、デバイスのシリアルポートを指定して回収できる:

```sh
python3 tools/recover_measurements.py /dev/cu.usbmodem12401
```

ポート名は接続で変わる場合がある。この回収コマンド自体はDTRやリセットを操作しない。USBの物理的な再接続による端末側の再起動は別である。

データベースは `.local/bridge.sqlite3`。履歴は自動削除しない。通信の復旧と電源障害の解消は別の受入条件として扱う。

端末内は最大16件の未送信履歴を保持する。約1秒ごとにRAMへ測定し、起動時・Wi-Fi起動前と、その後30秒ごとに不揮発領域へ保存する。満杯時は通常測定から古い順に置き換え、起動・再接続の記録を優先する。電源断前の最大約30秒分は失われる可能性がある。保存済み履歴は再接続時に再送し、Macで重複を除く。
