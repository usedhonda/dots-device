# 直接モードの質問・回答形式

次は `device_publish_question` のツール引数です。通常チャットへJSONを貼る指示ではありません。

```json
{
  "question_id": "demo-question-001",
  "text": "お昼はどちら？",
  "choices": [
    {"id": "ramen", "label": "ラーメン"},
    {"id": "curry", "label": "カレー"}
  ]
}
```

質問IDは1〜128バイト、本文は1〜4096バイト、選択肢は1〜4個です。候補IDは1〜48バイトで重複不可、表示名は1〜128バイトです。これらは直接モードの受付上限で、読みやすい長さではありません。表示名は6〜8文字、質問は短い日本語を推奨します。2候補ずつ表示し、長文は左側でスクロールします。

同じIDと同じ質問は冪等扱い、同じIDで内容を変えると拒否されます。未受領の回答がある間は新しい質問を受け付けません。実回答は `interaction_id`、`choice_id`、`request_id` で照合し、同じ実回答に `receipt_id` を記録します。1回の選択で回答し、追加の確認や送信画面は挟みません。

`device_publish_summary` は `summary_id` と `text` を受け、本文は24 Unicode文字以内です。同じID・同じ本文は冪等扱いで、同じIDで異なる本文は拒否します。要約受付はDotの実回答受領とは別です。

直接モードはsourceをrealとして記録します。旧Mac中継の240文字／8文字制限やsimulation形式は、[中継固有の形式](../bridge/README.md)です。直接モードのツール引数と混ぜないでください。
